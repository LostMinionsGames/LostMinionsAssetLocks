# Changelog

All notable public release notes for Lost Minions Asset Locks will be maintained here.

## 1.0.0-rc.1 — Current pre-release

The plugin descriptor identifies this build as a beta release candidate. This is not a final `1.0.0` release or a claim that a Fab listing is available.

### Documented capabilities

- Git LFS checkout and release workflows for managed Unreal assets.
- Content Browser lock status and team lock browsing.
- Lock owner, age, and timestamp visibility.
- Setup diagnostics and fail-closed status handling when verification is unavailable.
- Default-off administrative Force Release for a confirmed foreign lock, with authoritative post-operation verification and no automatic checkout.

Future entries will describe released customer-facing changes without reproducing internal development history.
